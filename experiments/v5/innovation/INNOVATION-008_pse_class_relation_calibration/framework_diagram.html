对称、限幅的 PSE 类别关系验证

第二版只回答三个问题：旧基线怎样、未见类走同一旧 PSE 怎样、再加安全类别关系注意力怎样。

1. 独立验证数据

100 个 pseudo-seen 类
每类固定留出 20% 图片评估 S
50 个 pseudo-unseen 类
使用 xlsa17 val_loc 评估 U / ZS
正式 test 缓存不加载
→

2. 对称文本路径

seen：7 句 → 旧句子 PSE → 基础原型
unseen：7 句 → 同一个旧句子 PSE → 基础原型
两组分开运行；unseen 前向恢复 RNG，不打乱后续 dropout
→

3. 安全类别关系

零起点：初始输出与 R1 完全相同
硬限幅：每类修正范数 ≤ 0.1
共享权重：seen / unseen 分组注意
CE 仍只使用 seen 列

三组对照

组别seenunseen类别关系
R0旧句子 PSE原始句子均值无
R1旧句子 PSE同一个旧句子 PSE无
R2旧句子 PSE同一个旧句子 PSE限幅、零起点、两组分开

限幅公式

correction = 0.1 × relation / max(norm(relation), 1)

因此修正量不会再出现第一版“配置写 0.1，实际平均达到原型 2.94 倍”的问题。训练校准和推理加分均不属于本轮。
