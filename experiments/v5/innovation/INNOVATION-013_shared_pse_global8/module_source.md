# PSE 来源与本次修改

来源机制是项目已有的句子级 PSE：让同一类别的多句话先交互，再形成类别文本原型。旧实现只增强 seen 类，unseen 类保留静态均值，因此训练规则和推理规则不对称，容易把 GZSL 分数推向 seen。

本次不是照搬旧实现，而是收缩为一个可解释模块：

1. 同一个共享自注意力同时处理 200 类的 8 句话，不存在类别专属参数。
2. 角色权重明确对应 6 个局部部位、全局外观和独特判别特征。
3. 有界残差门从 0 开始，初始输出严格等于纯 CLIP 全局基线。
4. 只产生一个全局文本原型，不接 patch 或旧局部分支。

假设：共享、对称的句子增强能够学习“哪些语义角色更稳定”，同时避免旧 PSE 只适配 seen 的分布偏移。
