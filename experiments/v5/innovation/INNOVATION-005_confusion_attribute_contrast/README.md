# 全局混淆类难负样本局部对比

- 问题：让局部分支专门区分全局最容易混淆的类别，能否增加 rescue 并减少 harm？
- 基线：直接对照 V5-INNOVATION-004，唯一新增是难负类损失。
- 唯一改动：在 local CE 上，用 detached global seen logits 选 top-5 非真类，加入 0.1 权重、0.1 margin 排序损失。
- 初筛：固定 seed 5；训练方案保持 50 epoch。
- 完成条件：独立 RUN 目录包含日志、最终指标；训练方案另含最佳模型。
- 停止条件：出现非有限数值、代码/输入变化或输出目录冲突时立即失败。
- 结果：已完成三种子，平均 `H=74.1770`；相对自身 global 平均 `+0.2542 H`，但仍未超过完整模型均值，因此只保留为局部残差纠错诊断，不晋级。详见 [result.md](result.md)。
