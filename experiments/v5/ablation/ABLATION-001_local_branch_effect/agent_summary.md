# 角色汇总

三个必需角色均已分别检查并给出 `allow`：

- Runner 监控角色确认服务器、停止和恢复路径；
- 接口角色确认 FULL 与 GLOBAL_ONLY 的唯一研究变量；
- 证据质量角色确认数据、收据、结果字段和结论边界。

正式 Runner 已通过 strict-3、参数表、实验绑定、数据指纹和干净冻结提交检查，并在服务器双卡完成四条 R5 补跑。训练期采用 `server_detached_role_only`，没有创建命名训练任务；当前主任务承担持续监控，仓库、服务器日志、收据和 Warehouse 是事实来源。

训练后结果角色确认三种子 H 配对差值为 `+0.25/-0.09/+0.09`，平均 `+0.08`。这表示局部分支的综合 H 收益很小且方向不稳定；三路 strict-3 训练后复核均为 PASS，正式结论已标记为 `completed_reviewed`。
