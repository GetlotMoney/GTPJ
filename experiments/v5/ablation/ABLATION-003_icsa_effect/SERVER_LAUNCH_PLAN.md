# V5-ABLATION-003 服务器启动计划

本文件只定义启动前的卡位和命令形状；当前没有启动任何训练。

## 固定分配

- 物理 GPU：`0`
- 进程可见卡：`CUDA_VISIBLE_DEVICES=0`
- 配置内设备：`cuda:0`（进程只看见这一张卡）
- 运行顺序：`RUN-001`（seed 5 第1次）→ `RUN-002`（seed 5 第2次）→ `RUN-003`（seed 17 第1次）→ `RUN-004`（seed 17 第2次）

## 唯一正式启动者

本轮只能由待实现并冻结的 `CAMP-20260809-v5-ablation100` 后台控制器启动。控制器完成前不可手工正式启动，也不能把单独调用训练脚本产生的结果记入正式账本。

控制器必须：

1. 只读取 frozen campaign map 中登记的分支、提交、配置路径和配置哈希；
2. 在 GPU 0 上按上面的四个 RUN 顺序串行调用准确训练入口；
3. 为每个 RUN 创建独立 Warehouse 目录，并写启动 receipt、结束 receipt、stdout 和 stderr；
4. 保留失败状态，不覆盖任何已有 RUN 目录。
