# V5-ABLATION-010 服务器启动计划

本文件只登记任务顺序，不提供绕过统一队列的训练命令。

## 固定分配

- 物理 GPU 1：由 `CUDA_VISIBLE_DEVICES=1` 隔离。
- 进程内设备：逻辑 `cuda:0`。
- 顺序：`RUN-001` → `RUN-002` → `RUN-003` → `RUN-004`。

## 唯一正式启动者

只能由冻结后的 `CAMP-20260809-v5-ablation100` 后台控制器正式启动。控制器完成前禁止手工正式启动，手工运行产生的结果不得写入正式参数表。

统一队列必须读取准确的代码提交、配置路径和配置哈希，为每个 RUN 建立互不覆盖的 Warehouse 目录，并分别保存启动记录、结束记录、标准输出和错误输出。某个 RUN 失败时保留错误并继续已冻结的其他任务，不得临时改参数。
