# 执行卡：论文读取 / Idea Discovery

用于读取论文、核对来源并提取可验证的创新假设。

## 最短闭环

1. 核对论文、官方页面或代码来源，记录可追溯引用。
2. 提取论文实际解决的问题、机制 claim、适用条件和局限。
3. 把候选机制翻译为 GTPJ 的 hypothesis、attachment point、最小实现和风险。
4. 长证据写入 Research；GitHub 只保存轻量来源索引和成熟 idea。
5. owner 只授权阅读时，不创建实验、不运行训练。

没有 verified source 或 owner 接受的 local heuristic，不把候选写成正式创新事实。当前通用规则见 `START_HERE.md` 和 `WORKFLOW_KERNEL.md`。
