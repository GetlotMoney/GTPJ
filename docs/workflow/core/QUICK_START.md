# GTPJ V6 快速入口

直接说 `查状态`、`读论文`、`调参`、`消融`、`复现`、`开新模块`、`升版本` 或组合实验即可。

Agent 先读 `START_HERE.md` 和 `WORKFLOW_KERNEL.md`，再选择一张 `playbooks/` 执行卡。正式训练固定准确 commit、`TEMPLATE.yaml` / `EXPERIMENT.yaml`、`PARAMETER_MATRIX`、数据/划分、seed 和评估口径；通过一次开跑检查后直接运行到独立 `RUN-xxx` 目录。

旧短口令、runtime gate 和命名线程说明见 `../archive/specs/WORKFLOW_PRE_V6_ARCHIVE.md`，只供历史回查。
