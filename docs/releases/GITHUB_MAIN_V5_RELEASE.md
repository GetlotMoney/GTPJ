# GitHub main 的 V5 干净发布范围

## 目标

让 GitHub 的 `main` 能清楚回答三件事：当前有哪些正式框架、V5 的准确代码起点是什么、局部分支消融得到了什么结果。

## 本次包含

- `FRAMEWORK-V5` 的身份、历史来源和框架图；
- `MODEL-V5-TEMPLATE-V1` 的分支、Tag、准确提交和行为合同；
- `V5-ABLATION-001` 的参数表、配置快照、数据身份、最终指标和结论；
- 方便阅读这些内容的 README、项目状态页和总索引。

## 本次不包含

- 训练 Python、实验专用控制器和临时调试脚本；
- 旧 `module_trials` 的整批历史；
- 原始日志、checkpoint、模型文件、数据集和缓存；
- 正在服务器运行的工作树及其未完成结果。

## 使用规则

`main` 只管理事实账本。普通 V5 实验和创新候选的第一次实现从 `model/v5-template-v1` 创建独立 `exp/v5/...` 分支；实验代码不回写到模板，也不能整条合进 `main`。如果创新已改出完整候选代码，候选自己的消融、调参和确认都从同一冻结候选提交独立开始；通过全部验证后，候选才可以晋级为新的平级正式框架。
