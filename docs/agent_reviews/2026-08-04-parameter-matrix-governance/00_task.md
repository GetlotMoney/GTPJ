## 2026-08-05 强度升级说明

后续命名 Codex 审核发现，改动不仅影响表格展示，还会改变正式 Runner 的冻结、结果写回和 Warehouse 产物核对。影响范围已升级为高，因此最终放行改用三轮只读审核；本目录保留为第一次方案的历史记录，新的最终审核包另行建立。

## 为什么是两轮

本次改动会改变正式实验的准入和结果入账规则，影响 tune、ablation、confirmation 与 module trial attempt；它不改模型、训练算法或评估指标，因此按中等影响执行两轮独立审核，而非三轮。

## 目标

从今天起，每个真实训练任务都要有一行参数记录，不能用“跑了 50/100 个”代替。正式规则需要保证：

- CSV 是机器查重与回填的唯一来源，Markdown 阅读版不能不同步；
- 正式动态路由在建批次前逐行核对冻结表；
- 普通版本实验和模块 Attempt 不能绕过参数表直接写成正式结果；
- 复跑、跨版本查重、配置快照、种子与 Warehouse 证据都能追溯；
- 历史记录只恢复可验证资料，不补造缺失的逐行数据。
