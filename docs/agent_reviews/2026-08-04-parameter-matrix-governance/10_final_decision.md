# 最终决定

- 日期：2026-08-04
- 影响判断：中等。它改变了以后实验的记录和开跑门槛，但不改变模型、训练算法或历史实验结论，因此采用两轮独立审核。

从即日起，GTPJ 的正式实验以“一个实际训练任务对应参数表中的一行”为准。新建实验先建参数表；每一行准备好实际配置、随机种子和变更说明后逐行冻结；整表验证通过、预运行冻结提交后，才允许进入正式训练；结果、产物和是否保留的结论再写回同一行。

正式入口见：

- `docs/workflow/protocols/parameter_matrix_protocol.md`
- `experiments/templates/PARAMETER_MATRIX_template.csv`

历史 `ATTEMPT-001` 至 `ATTEMPT-018` 不补造不存在的参数值。已有 Warehouse 原始材料时可以按来源补录；只有摘要时保留“只有摘要”的标记。

## 已知边界

参数表能防止以后重复调参和结果脱节，但不能自动恢复过去没有保存的参数。真正启动下一批训练前，仍需把该批实际配置逐行填入并冻结。
