# 第一轮独立审核：阻塞项

审核方式：两名临时只读 Agent 分别检查代码逻辑与文档/可用性；均未修改文件。

## 代码逻辑审核的初始阻塞项

- 动态 top-rank 复跑只留下 `top_rank:n`，回填后没有解析真实来源任务与实际指纹。
- 查重没有带上版本和代码引用，会把不同版本的同一配置误判为重复。
- 回填引用了运行缓存而不是 Warehouse，并允许未知任务或调试计划污染正式表。
- 结果登记可使用错误 seed、错误配置或已完成行。

## 文档/可用性审核的初始阻塞项

- 规则写“所有新实验”，但版本级和模块级正式结果可以绕过参数表。
- CSV 与 Markdown 阅读版没有一致性校验。
- 普通实验没有跨项目查重，也不能核验 `config_fingerprint` 是否对应真实配置。
- 多行矩阵不能逐行冻结：第一行冻结会被其他草稿行阻断。

结论：第一轮为 `block`；以上问题在第二轮前全部修复并补测试。
