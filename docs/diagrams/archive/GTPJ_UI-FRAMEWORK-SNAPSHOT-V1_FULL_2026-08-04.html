📥 输入

图像 batch（B 张），GPT 类别文本描述，CUB 200 类别集合（150 seen / 50 unseen）。

↓

🧊 Frozen CLIP 编码器

冻结的 ViT-L/14@336px 提取视觉特征，不参与梯度更新。

clip_features [B, 577, 768] 冻结参数
↓

🔀 特征拆分

拆出全局 CLS token 和 576 个空间 patch tokens。

CLS [B, 768]  |  patches [B, 576, 768]

📝 文本输入

GPT 生成的类别描述 → 冻结 CLIP 文本编码器 → 原始文本嵌入。

seen_text [C_seen, 768]   unseen_text [C_unseen, 768]
↓

🧠 PSE / CLIP-A-self

渐进式语义增强。用多头自注意力在句子级嵌入上增强文本原型；outer_ratio 控制残差混合强度。

all_text [C, 768]（pse_outer_ratio=0.65 残差混合） 可训练
↓

🎯 ICSA

图像条件语义适配器。用图像 CLS token 产生逐样本的条件注入，让文本原型携带当前图像的实例信息。

all_text_cond [B, C, 768]（icsa_ratio=0.008 残差注入） 可训练
↓

🌐 全局分数

图像 CLS 与条件文本原型做余弦相似度，经可学习温度缩放。

S_global [B, C] = cos(CLS, all_text_cond) × exp(logit_scale)

🔍 FGVD 频域 Patch 选择

频率引导的视觉解耦。用 FFT 频域滤波分析每个 patch，选出 K=32 个最有信息量的视觉 token。

selected_patches [B, 32, 768]（formula=v2_abs_mean） 可训练
↓

📐 几何感知编码器 (FAE)

BoxRelationalEmbedding 生成 24×24 网格的相对位置几何嵌入，GeometryDecoupledEncoderLayer 做几何解耦自注意力。

FGVD memory [B, 32, 512]
↓

🔗 BVSA 跨模态 Transformer

双向视觉-语义对齐。V2S decoder（文本→视觉）和 S2V decoder（视觉→文本）互相查询。v5 关键：接收条件文本。

S_local [B, C] = 0.5 × S_s2v + 0.5 × S_v2s v5: bvsa_text_mode=conditional

➕ 分数融合

固定加权加法：全局分数 + 局部分数。

S_final [B, C] = S_global + 0.2 × S_local
↓

📊 损失函数组合

主损失 + 5 个辅助正则化损失：

CE主分类损失
Consistencyλ=0.05, T=2.0
Topologyλ=0.1, Pearson
BMDDλ=0.05, S2V↔V2S KL
MPPλ=0.05, masked pred
Negλ=0.01, 负样本抑制
↓

🎓 训练策略

3 阶段学习率：lr_stages = 20 + 20 + 10 = 50 轮。
Cosine annealing + restart_from_best。

lr: 1e-3(20ep) → 1e-4(20ep) → 1e-5(10ep)

🎯 SGMP 辅助模块

语义引导的掩码预测。选 TopK patch 做 masked prediction，利用 FGVD 主记忆作为上下文；负样本对比抑制。

L_mpp (topk=8) + L_neg (margin=0.2) context: fgvd_main_memory
↓

📏 GZSL 评估

Seen/Unseen 严格隔离；无 unseen label 泄漏。

U / S / H / ZS 四指标 H = 2×U×S/(U+S)
↓

🔬 研究前沿：Dynamic Residual Routing (IDEA-0003 / TRIAL-001)

在 v5 主线上增加 4 个动态门控模块，让模型对每个样本/类别自适应调节残差强度和路由方向。 最佳单次 H=75.11（DR-095），但 5 次 exact repeat 均未能复现（最高 74.71）。状态：blocked, revise。

🎛️ local_gate

控制 BVSA 局部分支在最终分数的贡献权重。取代固定 local_weight=0.2。

modes: fixed / sample / class

🎛️ icsa_gate

控制 ICSA 图像条件注入的强度。取代固定 icsa_ratio=0.008。

modes: fixed / sample / class

🎛️ direction_gate

控制 BVSA 中 S2V 与 V2S 两个方向的混合比例。取代固定 weight_s2v=0.5。

modes: fixed / sample / class

🎛️ pse_gate

控制 PSE 文本原型增强的残差强度。取代固定 pse_outer_ratio=0.65。

modes: fixed / class (class_uses_sample=false)
