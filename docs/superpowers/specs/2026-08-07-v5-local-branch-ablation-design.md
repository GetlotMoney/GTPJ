# V5 局部分支消融设计

日期：2026-08-07  
实验：`V5-ABLATION-001`  
母版：`MODEL-V5-TEMPLATE-V1` / `model/v5-template-v1` / `2f5fa5e631ef82658d4bac587cdfd17f3534cb35`

## 要回答的问题

V5 最终分数由全局分数和局部分数组成，但现有量级检查只说明局部分数在一次前向计算中的直接加分较小，不能说明局部分支在训练过程中没有帮助。本实验要分开回答两个问题：

1. 同一个完整 V5 模型里，局部分数对最终预测直接改变了多少；
2. 从头训练时彻底去掉局部子系统，最终 GZSL 分类性能会下降、持平还是上升。

## 公平比较边界

完整组和无局部组必须保持以下内容一致：

- CUB 数据划分、类别顺序、标签映射和评估函数；
- CLIP ViT-L/14@336px 缓存、GPT-5.5 文本缓存及其文件指纹；
- PSE、ICSA、全局余弦分类分数和拓扑损失；
- batch size、优化器、学习率三段计划、训练轮数和随机种子；
- 每个种子都从头训练，不加载另一组的 checkpoint。

唯一主要差异是局部子系统是否存在。

## “彻底去掉局部”的准确含义

无局部版本删除：

- FGVD 局部块筛选与几何编码；
- BVSA 双向局部视觉—语义对齐；
- SGMP 局部块辅助预测；
- `global + 0.2 * local` 中的局部加分；
- consistency、BMDD、MPP 和 negative semantic 这些依赖局部路径的损失。

无局部版本保留：

- PSE，因为它生成全局文本原型；
- ICSA，因为它用 CLS 全局图像特征调整文本原型，也参与全局分数；
- CE 分类损失和 topology 拓扑损失。

模型输入仍接受 `[B（图片数量）, 577（1 个 CLS 全局特征加 576 个局部块）, D（特征维度）]`，但无局部版本只读取第 0 个 CLS。这样数据和评估入口完全相同，同时任何局部块数值都不可能影响输出。

## 判定方式

每个种子先做配对差值：

`局部贡献 = H(完整 V5，同种子) - H(无局部，同种子)`

然后报告三组差值、平均差值、离散范围，以及 U、S、ZS 的同样变化。由于只有三个种子，本轮用于判断方向和实验价值，不把显著性检验包装成确定结论。

- 三个种子大多同方向且平均 H 明显下降：局部分支有稳定价值；
- 差值围绕 0 波动：局部分支贡献低于当前训练噪声，需要结合参数量和算力判断是否保留；
- 无局部组稳定更好：局部分支可能产生干扰，应再做确认实验后考虑瘦身晋级；
- 只有个别种子明显：先查训练随机性和最优 epoch，不直接写论文结论。

## 后续模块消融队列

第一批完成后，按同样原则逐个关闭，不能一次去掉多个主因素：

1. PSE；
2. ICSA；
3. FGVD 的块选择；
4. FGVD 的几何编码；
5. BVSA 的 S2V 方向；
6. BVSA 的 V2S 方向；
7. consistency 损失；
8. topology 损失；
9. BMDD 损失；
10. SGMP 的 MPP 损失；
11. SGMP 的 negative semantic 损失；
12. 纯 CLIP ViT-L/14@336px；
13. CLIP + GPT-5.5 文本原型，但不加 V5 训练模块。

只有当前一项得到完整结果并完成质量检查后，才自动准备下一项，避免同时产生大量不可解释的运行。

## 风险和退出条件

- 服务器提交、数据指纹或配置指纹不一致时不启动；
- 任一代码接口测试、评估语义检查或审核门失败时不启动正式训练；
- GPU 出现其他训练进程或显存不足时暂停对应队列；
- 训练失败保留日志并登记失败，不静默重跑或换参数；
- 本实验不改变技术栈，因此不新增技术路线版本；完成后只在 `docs/TECH_STACK_HISTORY.md` 记录“未改变技术栈”的实验说明（若现有留痕格式要求）。
