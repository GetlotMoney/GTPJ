# 初始独立审核结论

## 审核强度

本次会改变模型入口、训练数据路线、评估实现和历史权重转换规则，属于会影响正式实验含义的跨模块改动，因此使用三名独立只读审核人；机器测试不能被审核替代。

## 数学与评估审核：阻断

- 合同声称支持 `[B, 576, D]`、`[B, 1, D]` 和 `[B, D]`，但 conditional BVSA 实际需要 CLS，合同与真实路径不一致。
- `local_weight` 可以改成 0.3，模型会正常执行，固定 0.2 没有在代码里锁死。
- U/S/H/ZS 只检查训练源码里有没有字符串，没有执行非连续 seen/unseen 类别映射和 H 公式。
- `class_attr`、`attr_text_embeds` 和 BVSA 的 `cls_token` 形参未参与计算。

## 代码瘦身与转换安全审核：阻断

- 模型仍保留无几何 FGVD、多个 SGMP 上下文、两种文本条件和关闭模块的路线。
- 训练入口会按缓存是否存在切换多视角、patch、CLS-only、在线提取，会按配置切换多种文本、续训、微调、AMP 和评估偏置。
- checkpoint 转换器按宽前缀猜字段，不核对单键形状；冲突时没有失败收据。
- 先检查再 `os.replace` 存在并发覆盖窗口，输入变化后也可能留下输出。

## 历史与复现审核：放行本地候选

- `v5` Tag 和参考 commit 一致，旧 `experiments/module_trials` 子树在 base/head 完全相同。
- 历史真实模型源码、完整 `state_dict`、固定输入、7 项损失和四组关键梯度对照链有效。
- 治理校验均通过，且没有越界声称服务器正式精度已确认。

初始总决定：`block`。先完成数学、训练路线和转换安全修复，再复审。
